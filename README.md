# 💰 MONEY PANEL - Premium Hacker Edition

A professional SMS panel with premium green hacker theme.

## Features

- 💰 Premium Hacker Theme (Matrix Green)
- 📱 Device Management
- 📨 SMS Forwarding
- 📞 Call Forwarding
- 💬 Message Management
- 🔥 Firebase Integration
- ⚡ Real-time Updates

## Railway Deployment

### Quick Deploy

1. Push this code to GitHub
2. Go to [Railway](https://railway.app)
3. Click "New Project"
4. Select "Deploy from GitHub repo"
5. Select your repository
6. Railway will auto-detect and deploy

### Manual Deployment

1. Install Railway CLI:
```bash
npm install -g @railway/cli
```

2. Login to Railway:
```bash
railway login
```

3. Initialize project:
```bash
railway init
```

4. Deploy:
```bash
railway up
```

## Local Development

1. Install dependencies:
```bash
npm install
```

2. Start server:
```bash
npm start
```

3. Open browser:
```
http://localhost:3000
```

## Environment Variables

No environment variables required. All configurations are handled internally.
